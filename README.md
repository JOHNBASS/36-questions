# 36個問題 — 讓兩個人更靠近

> 一個單檔的互動網頁體驗，靈感來自心理學家 **Arthur Aron (1997)** 的研究：兩個人輪流回答 36 個逐漸深入的問題，再加上最後 4 分鐘的「凝視」，能在短時間內建立真實的情感連結。

🔗 **線上體驗**：<https://johnbass.github.io/36-questions/>

## 特色

| 功能 | 說明 |
|------|------|
| 📖 背景介紹 | Arthur Aron 研究的故事 |
| 🃏 問題卡片 | 36 題分三組，逐漸深入 |
| ↔️ 輪流提示 | 標示現在輪到誰回答 |
| ⏱️ 每題計時 | 可設定 2／3／5 分鐘或不計時 |
| 📝 回答記錄 | 本地輸入，邊打邊自動儲存 |
| 🔀 跳過題目 | 標記未完成的題目 |
| 👁️ 對視倒數 | 最後 4 分鐘的凝視計時器 |
| 💾 進度保存 | 關掉瀏覽器再開可繼續 |
| 📄 匯出 PDF | 把這次的對話留成紀念 |
| ⌨️ 鍵盤導航 | 左右方向鍵切換題目 |

## 隱私

所有名字與筆記**只存在你自己的瀏覽器** (`localStorage`)，不會上傳到任何伺服器。這是純前端的靜態網頁，沒有後端、沒有追蹤。

## 技術

- 單一 `index.html`，零相依套件、零建置流程
- 原生 HTML / CSS / JavaScript
- 由 GitHub Pages 託管

## 在本機開啟

直接用瀏覽器打開 `index.html` 即可，不需要任何伺服器。
